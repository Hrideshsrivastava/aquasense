# Legacy: abstract-round prototype

`abstract-prototype/` is the first AquaSense prototype built for the abstract
round: a FastAPI app with Google sign-in, a rule-based digital twin and a
stand-alone browser demo (`abstract-prototype/demo/index.html`, open it
directly in a browser).

It has been replaced by the build-plan prototype in the repository root (ESP32 rig,
Flask cloud, Streamlit console, Raspberry Pi handheld, ML models). The code is
kept for reference. To run it, `cd legacy/abstract-prototype` and follow its README.
